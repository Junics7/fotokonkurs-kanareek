# Фотоконкурс канареек

Рабочий русскоязычный статический сайт конкурса с Supabase.

## Возможности
- адаптивная главная страница;
- галерея и фильтрация;
- реальные заявки участников;
- загрузка JPG/PNG/WEBP до 10 МБ в Supabase Storage;
- модерация через статус `pending` / `approved`;
- реальные голоса в таблице `votes`;
- защита от повторного голоса одного браузера за одну фотографию;
- рейтинг участников;
- тестовые фотографии.

## Supabase
Frontend использует только publishable key. Service-role ключ в репозитории отсутствует.

Для публикации заявки модератору нужно изменить `participants.status` с `pending` на `approved` в Supabase Dashboard.

## Публикация
Репозиторий подготовлен для статического деплоя на Vercel или GitHub Pages. Сборка не требуется.
